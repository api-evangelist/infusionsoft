# Keap (formerly Infusionsoft)

> Sales and marketing automation CRM for small businesses: contact management, tagging,
> email marketing, campaign/automation sequences, e-commerce orders and subscriptions,
> sales pipelines, appointments and invoicing. Keap exposes two generations of REST API
> plus a separate Pipelines (deals) API, all over OAuth 2.0. Keap is owned by Thryv Holdings.

Generated 2026-08-13 by the API Evangelist enrichment pipeline from artifacts in
https://github.com/api-evangelist/infusionsoft. Keap does not publish its own /llms.txt
(probed 404 on api.infusionsoft.com, api.keap.com, developer.keap.com, developer.infusionsoft.com

not served by the provider.

## What an agent needs to know first

- Base URL: `https://api.infusionsoft.com/crm` (also reachable as `https://api.keap.com/crm`).
- Every call is `Authorization: Bearer <token>`. Three credential types share that header:
  OAuth 2.0 access tokens, Personal Access Tokens, and Service Account Keys.
- There are NO granular OAuth scopes. `scope=full` is the only valid value, so any token
  that can read contacts can also delete orders and cancel subscriptions. Treat every
  Keap token as a full-account credential.
- There is NO idempotency key anywhere in the API. Do not blind-retry a POST after a
  timeout: `createContact` and `createOrder` will duplicate.
- v1 and v2 are different APIs, not versions of one. v1 pages with `offset`/`limit`;
  v2 pages with opaque `page_token`/`page_size` and filters with `filter`.
- Webhooks (REST Hooks) exist ONLY on v1. There are zero hook operations in v2.
- Custom field ids are per-tenant. Read the `/model` endpoint before writing custom data.

## Authentication

- Refresh tokens ROTATE: every refresh returns a new refresh token that must be persisted.
- [Developer keys portal](https://keys.developer.keap.com/)

## Rate limits and quotas

- [Token quota and usage measurements](https://developer.keap.com/api-token-quota-and-usage-measurements/)
- OAuth2 token: 1,500/minute and 150,000/day per key+secret pair.
- PAT / Service Account Key: 10/second, 240/minute, 30,000/day per key.
- Application instance (tenant, since 2026-06-08): 10,000/minute and 250,000/day.
- Unmetered spike arrest at 25 calls/second.
- Runtime headers: `x-keap-product-quota-*`, `x-keap-product-throttle-*`, `x-keap-tenant-throttle-*`.
- Exhaustion returns 429. No `Retry-After`. Back off exponentially with jitter.

## Events

- [REST Hooks documentation](https://developer.keap.com/rest-hook-documentation/)
- Subscribe with `POST /rest/v1/hooks` (`{eventKey, hookUrl}`), then activate with
  `POST /rest/v1/hooks/{key}/verify`. List subscribable events with `GET /rest/v1/hooks/event_keys`.
- Deliveries are batched (max 1,000 objects) and carry ids plus an `apiUrl`, not the object body.
- Four delivery attempts (30-60s, 30-60s, 5m, 30m); a fourth failure or a 410 marks the
  subscription Inactive. There is NO delivery signature - Keap does not sign webhooks.
